# PLE agent harness — "contract first"

An open-source agent harness for [Physical-Engineering's Last Exam](https://ple-bench.com)
(Google · Kaggle hackathon). It is a WebSocket server that drives an
OpenAI-compatible chat model through long-horizon engineering tasks inside a
container, and it is built around one finding from the dev set:

> A large part of the score is decided before the model does any engineering —
> and a second part is decided by whether the model's own code runs at all.

## What is in here

| file | purpose |
|---|---|
| `serve.py` | agent loop, container tools, MCP bridge, context compaction, deadline management |
| `ple_ext.py` | PLE extensions: deliverable detection, in-container validators, the gate, deterministic v0 materialisation, error-class recovery hints |
| `taskbridge.py` | the kit's serve protocol (WebSocket, protocol v1) |
| `submission.yaml` | model declaration, install and serve commands |
| `artifacts/` | what the harness produced on the public dev tasks (generated by `eval/run.py`) |

## How it works

1. **Deliverable contract.** At task intake the instruction is parsed for the
   graded paths and their required members; the contract is injected into the
   system prompt before the model starts.
2. **Deterministic v0.** At step 8, if nothing has been delivered, the harness
   builds a valid artifact itself — copying members from `templates/`, synthesising
   empty-but-valid files of the right type, and zipping them — then tells the
   model to improve it in place. An unparseable or absent deliverable is a hard
   zero on this benchmark, so the harness refuses to leave that to chance.
3. **Parallel tools.** A tool batch is dispatched with `asyncio.gather` behind a
   semaphore of 8, the protocol's in-flight limit.
4. **Error-class recovery hints.** Every failed command gets a short hint keyed to
   its error class (AttributeError → inspect the signature first; SyntaxError →
   write a file and edit it; ModuleNotFoundError → there is no network).
5. **Gate.** Before the model may finish, every deliverable is opened inside the
   task container with the real library (zipfile / openpyxl / python-docx / fitz /
   ifcopenshell / ezdxf). Failures are fed back for up to two repair rounds.

## Measured effect (dev set, `wind-diaphragm-shear`)

| variant | deliverable | register precision | score | agent s | input tokens |
|---|---|---|---|---|---|
| reference sample | never written | — | — | — | 0.35 M |
| + contract, gate, parallel tools | valid package | 0.55 → **voided** | 0.000 | 2,878 | 10.13 M |
| + discipline rules, v0, hints | valid package | **1.00** | **0.032** | **1,002** | **6.50 M** |

Command-failure rate over the same task fell from 31.6% to 23.9%.

## Running it

```bash
# build + smoke test exactly as the evaluator does
uv run python -m kit check ../ple-agent-harness

# run the 29 public dev tasks and write artifacts/
uv run python eval/run.py ../ple-agent-harness --env-file local.env
```

`local.env` holds the model key and the judge settings and is never committed.

## Configuration

| env var | default | meaning |
|---|---|---|
| `COMPACT_AT_TOKENS` | 150000 | compact the conversation above this prompt size |
| `TOOL_RESULT_CHARS` | 30000 | clip each tool result to this many characters |
| `KEEP_RECENT_RESULTS` | 12 | never trim this many most-recent tool results |
| `MAX_OUTPUT_TOKENS` | 32000 | output ceiling asked of the model |

These are env-tunable so the same harness can be swept across the cost curve.
